# Using Frontmatter Metadata in Docusaurus

The wp-hooks-documentor now adds rich metadata to the frontmatter of generated markdown files, enabling powerful Docusaurus features.

## Frontmatter Fields Added

Each generated hook documentation file includes:

```yaml
---
id: hook_id
title: "Action - hook_name"
sidebar_label: "hook_name"
since: "1.0.0"                           # Primary version introduced
tags: ["since-1.0.0", "since-2.0.0"]    # All versions (for filtering)
deprecated: true                         # If hook is deprecated
api: true                                # If marked as public API
internal: true                           # If marked as internal use
---
```

## Benefits & Use Cases

### 1. Version Badges in Sidebar

**Using Docusaurus Tags:**
The `tags` field automatically creates filterable tags in Docusaurus. Enable in `docusaurus.config.js`:

```js
module.exports = {
  presets: [
    [
      '@docusaurus/preset-classic',
      {
        docs: {
          // Enable tags
          showLastUpdateTime: true,
          showLastUpdateAuthor: true,
        },
      },
    ],
  ],
};
```

### 2. Custom Version Badge Component

Copy `VersionBadge.jsx` to `src/components/` and use in any custom page:

```jsx
import VersionBadge from '@site/src/components/VersionBadge';

<VersionBadge
  version="2.0.0"
  deprecated={true}
  api={true}
/>
```

**Result:**
```
[Since 2.0.0] [⚠️ Deprecated] [✅ Public API]
```

### 3. Filter Hooks by Version

**Using Docusaurus Tags Plugin:**

Tags are automatically created for each version:
- `since-1.0.0`
- `since-2.0.0`
- `since-3.0.0`

Users can click these tags to filter hooks introduced in that version.

### 4. Custom Plugin for Advanced Features

Install the included plugin:

```js
// docusaurus.config.js
module.exports = {
  plugins: [
    './plugins/docusaurus-plugin-hook-versions',
  ],
};
```

This creates automatic pages:
- `/hooks/by-version` - All hooks organized by version
- `/hooks/whats-new/2.0.0` - New hooks in version 2.0.0
- `/hooks/deprecated` - List of deprecated hooks
- `/hooks/api` - Public API hooks only

### 5. Version-Based Search

**Algolia DocSearch Configuration:**

```json
{
  "index_name": "your_plugin_hooks",
  "start_urls": [
    {
      "url": "https://docs.example.com/hooks/",
      "selectors_key": "hooks",
      "tags": ["hooks"]
    }
  ],
  "selectors": {
    "hooks": {
      "lvl0": "header h1",
      "lvl1": "article h2",
      "lvl2": "article h3",
      "text": "article p, article li",
      "version": {
        "selector": "//meta[@name='docusaurus_tag']/@content",
        "type": "xpath",
        "global": true
      }
    }
  }
}
```

### 6. Sidebar Customization

**Show version next to hook names:**

```js
// sidebars.js
module.exports = {
  hooks: [
    {
      type: 'autogenerated',
      dirName: 'hooks',
    },
  ],
};
```

**Custom sidebar with version badges:**

```js
// src/theme/DocSidebarItem/index.js
import React from 'react';
import DocSidebarItem from '@theme-original/DocSidebarItem';

export default function DocSidebarItemWrapper(props) {
  const { item } = props;

  if (item.customProps?.since) {
    return (
      <div>
        <DocSidebarItem {...props} />
        <span style={{fontSize: '0.8em', color: '#888'}}>
          {item.customProps.since}
        </span>
      </div>
    );
  }

  return <DocSidebarItem {...props} />;
}
```

### 7. Deprecation Warnings

**Automatic warning banner for deprecated hooks:**

```js
// src/theme/DocItem/index.js
import React from 'react';
import DocItem from '@theme-original/DocItem';
import { useDoc } from '@docusaurus/theme-common/internal';

export default function DocItemWrapper(props) {
  const { frontMatter } = useDoc();

  return (
    <>
      {frontMatter.deprecated && (
        <div style={{
          backgroundColor: '#fff3cd',
          border: '1px solid #ffc107',
          borderRadius: '4px',
          padding: '12px',
          marginBottom: '20px',
        }}>
          <strong>⚠️ Deprecated:</strong> This hook is deprecated and may be removed in a future version.
        </div>
      )}
      <DocItem {...props} />
    </>
  );
}
```

### 8. API vs Internal Differentiation

**Filter sidebar to show only public API hooks:**

```js
// docusaurus.config.js
module.exports = {
  themeConfig: {
    navbar: {
      items: [
        {
          type: 'doc',

        },
        {
          to: '/hooks/api',

          position: 'left',
        },
      ],
    },
  },
};
```

### 9. What's New Pages

**Automatic version changelog generation:**

The plugin creates a page for each version showing new hooks:

`/hooks/whats-new/2.0.0` displays:
- All hooks introduced in version 2.0.0
- Deprecated hooks in this version
- API changes

### 10. Enhanced Search Experience

**Filter search results by version:**

```jsx

  const allDocs = useAllDocsData();
  const [version, setVersion] = useState('all');

    version === 'all' || doc.frontMatter.since === version

```

## Installation Steps

1. **Copy Component Files:**
   ```bash
   cp docusaurus-examples/VersionBadge.jsx your-site/src/components/
   cp docusaurus-examples/HooksByVersion.jsx your-site/src/components/
   ```

2. **Install Plugin:**
   ```bash
   cp docusaurus-examples/docusaurus-plugin-hook-versions.js your-site/plugins/
   ```

3. **Update Configuration:**
   ```js
   // docusaurus.config.js
   module.exports = {
     plugins: [
       './plugins/docusaurus-plugin-hook-versions',
     ],
   };
   ```

4. **Generate Documentation:**
   ```bash
   wp-hooks-documentor generate
   ```

## Summary

Adding `@since` and other metadata to frontmatter enables:

✅ **Better Organization** - Filter and organize hooks by version
✅ **Enhanced Navigation** - Version-based navigation and filtering
✅ **Improved Discoverability** - Search and filter capabilities
✅ **Visual Indicators** - Badges for version, deprecation, API status
✅ **Automatic Pages** - What's new, deprecated, API listings
✅ **Better SEO** - Structured metadata for search engines
✅ **User Experience** - Version compatibility at a glance
✅ **Developer Workflow** - Quick access to version history

The frontmatter metadata transforms static documentation into an interactive, version-aware experience!
